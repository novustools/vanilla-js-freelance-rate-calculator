# Vanilla JS Freelance Rate Calculator Logic

This repository contains the core, dependency-free JavaScript math logic for calculating sustainable freelance hourly and daily rates. 

Built for independent professionals and developers who need to calculate gross revenue targets, billable hours efficiency, and tax/expense breakdowns without external libraries.

For the full, interactive enterprise tool with visual income breakdowns, currency conversions, and custom print layouts, visit the [NovusTools Freelance Rate Calculator](https://novustools.com/freelance-rate-calculator/).
